2026-10-11: Mac autosave and installation results

This entry records completed experiments and individual acceptance gates. It is not a packaged application release.

  • Three matched Mac replacement-autosave pairs for a 1 MiB fixture reduced command medians from 266.735 to 172.400 ms (35.4% between arm medians). Paired reductions were 19.1–42.8%, with exact source and recovery checks passing. Measurement report; successful Mac and Linux experiment run.
  • The actual Mac source installer, default/guard-opt-out/stock launchers, combined appearance-plus-autosave save/recovery checks and whole-original-runtime preservation gate passed. Run 38064415026 remained red because an independent expansion-replay preparation test failed; subsequent replay steps were skipped.
  • App-local Mac appearance and exact restoration passed in the macOS job of run 38055256934. Its separate Linux job failed a preservation gate.
  • The preserved Rust preview passed compilation and real-runtime CI checks on Linux and macOS in run 38050843404. Those checks belong to the earlier architecture and do not prove retained-host native UI behavior.

Installation requires the full official Racket 9.3 distribution. A signed or packaged Mac app is not provided. Windows remains untested. Mac installation evidence. Combined appearance-plus-autosave performance has not been retimed; initial Mac lexer-validity waits were about 34–40 seconds on the measured large fixture.
