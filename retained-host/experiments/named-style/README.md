# Named-style lookup experiment: local source handoff

This package composes four independently reviewed immutable source packages,
without changing any member bytes. `SOURCE-COMPOSITION.json` records the exact
owner freezes and hashes. No Racket execution, native compilation, measurement,
publication or CI trigger has occurred for this candidate. Remote publication is
on an explicit authorization hold. An operational CLI switch is not permission.

The candidate remains default-off. It changes only the private named-style
lookup implementation; creation, notifications, mutation order and all public
style/editor calls remain original. Stock source SHA256 is
`2e06742f956c3de50847bbb429c400af78303c68e0deba1ebc865a619534bde0`;
candidate is
`74eb24f0d6485187c9700cca421f4299dee67ea092a811d56b737972b2204c6d`.
Only `OPENRACKET_NAMED_STYLE_INDEX=1` enables it. Previous binding, interval,
xref and scheduling candidates must stay absent. No delivered preview is changed.

## Components and later native gate order

1. `production/`: exact complete-module stock/unset/0/unexpected/1 differential,
   typed deliberate-failure control, and bounded publication/interruption tests.
   See `production/NATIVE-PLAN.md` for the exact executable/source/prefs/report
   command and `production/scripts/overlay.py --help` for the reversible,
   explicit-disposable-root applier. Python models are not native evidence.
2. `editor/`: four independent actual-runtime stock/stock-again/off/on editor
   captures. Complete ordered initial/incremental lexer tokens, styles and paren
   endpoints; real rich text, image/nested-editor identity and standard WXME
   save/reload are compared. See its README for exact command, bounds and limits.
3. `controls/`: three genuine unchanged stock/off/on Check Syntax host controls,
   actual PNG/READY/exit proof, ordinary host editing/undo/redo and Run; four
   unchanged actual annotation/rename traces. Every trace caller is truthfully
   `--mode stock` because xref is unchanged. The external named-style labels do
   not pretend those worker traces prove GUI style activation. The graph check
   covers the original filtered eight-edge output; its exact scope is retained.
   All native host, helper and dependency modules must explicitly compile first.
4. `performance/`: mandatory zero-skip native helper preflight, then identical
   common observation insertions in two independent runtime clones, and six
   interleaved genuine GUI trials at the actual isolated 256 MiB limit. See
   `performance/CI-CONTRACT.json` for the preserved order and bounds. Gate every
   trial on real source/lexer/annotation/terminal/monitor completion, heartbeat
   cleanup and actual same-style-list workload lookup/hit evidence. Keep full
   post-readiness graph parity. No synthetic cache prewarming, outlier removal,
   rerun substitution, deadline widening or instrumented speed claim.

The outer CI owner must use independent deep runtime copies, fresh per-process
preferences/addons, exact source hashes and unconditional pristine runtime
before/after witnesses. Correctness failures block timing, while independent
failure evidence must still be collected. Clear inherited experiment/resolver
variables before calling runners that own their profiles. Preserve all complete
stdout/stderr, process status, JSON, PNG and native compile logs. The normal Quit
and light-mode product acceptance packages are separate functional work and must
not be folded into this performance experiment. Quit is the next functional
priority once permission to run the native gate resumes.

All new native behavior is unknown until those real gates pass. The source plan's
broader adoption requirements, including platform and arbitrary-workload
coverage, are not satisfied by these Mac fixtures. No speed improvement or
product-adoption decision is implied by this handoff.

## Portable checks and relocation

The checked-in source packages are unchanged. For the inherited GUI transform
source tests, set `GUI_TEST_SOURCE_DIR` explicitly to the verified official
DrRacket private source directory when this composition is relocated. Do not
substitute a missing fixture with generated or unverified source.

Portable totals: 46 production source/applier checks and 15,000 model identity
comparisons; 31 editor checks; 31 controls checks plus 70 accepted/derived trace
and 37 original trace mutation invocations; 103 telemetry checks. These totals
include inherited test invocations, not unique native behaviors or acceptance
rows. Native tests and measurements remain unrun.
