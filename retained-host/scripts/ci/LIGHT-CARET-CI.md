frozen native source, host wait, renderer, evaluation setting, or product byte.

patched `tool/info.rkt` current-line foreground entry.

## Preparation and native scope

Each arm has its own independent, no-hardlink official runtime clone. Complete
original/shared runtime and source witnesses precede setup; every final witness
is attempted independently, even if another witness or a native command failed.
Full trees stay in runner-local evidence; public transport contains exact hashes,
entry counts and every changed member, without unnecessary absolute paths.

Before unchanged accepted setup, a read-only installation-only query proves
`drracket`, `htdp-lib` and `gui-lib` are already present in the selected official
runtime. Thus the accepted setup's missing-package download branch is not used.
Setup's preparation-only profile may perform its accepted initialization. That
profile is never used as either the compile/control or actual GUI profile.
Both later profiles start absent, are registered through official local-only
`--deps fail` package operations, use their own addon/compiled root, and receive
no copied preferences or memory-limit setter. A read-only preference witness
refuses a private memory-limit override. The measured profiles retain stock128.
The unchanged discovery proof verifies actual loaded package source and tool
info-domain registration. `-U` is used only for the preliminary installation
inventory query, never for private registration, reader, compile, controls or GUI.

Each arm reader-checks all22 modules in30 seconds, then compiles exactly those22
in180 seconds. All12 standalone invocations run directly with separate30-second
receipts and complete streams. Typed intentional negatives must exit1..123,
match their unique injection/assertion markers and never emit an OK marker.
The caret adapter extends the inherited namespace check to handle the new
`FAILURE control=...` marker spelling, leaving the frozen validators unchanged.

Only the original and patched modern-light Macro Stepper GUI cases run. Each
uses a fresh native profile/process and the exact focused host. The outer60-second
budget begins before spawn and is never restarted. The real macOS screencapture
must follow successful READY and finish before acknowledgment, both inside the
original20-second window and outer deadline. Absolute monotonic start, READY,
capture, ACK, observed exit and deadline timestamps are retained. All original
PNG bytes and GUI streams are preserved, including failed evidence.

The durable safety ledger is explicitly initialized once. Missing, malformed,
interrupted, prelaunch or uncertain-cleanup state blocks every later native
command across phases. Owned processes are cleaned even if ledger reads/writes
fail. The only allowed concurrent child is the bounded capture attached to its
tracked GUI lease. Filesystem witnesses and diagnostic transport remain allowed
when native work is blocked.

## Evidence and conditional acceptance

`decode-light-caret-evidence.py LOG NEW_DIRECTORY` reconstructs lossless complete
byte wrappers, preserving partial failures. `--validate` additionally runs both
frozen arm validators and the pair validator. Decoding alone makes no acceptance
claim. Every missing mandatory file is explicitly incomplete. Failed setup and
all individual command supervisor/stdout/stderr files are transported separately;
one missing member or transport failure never suppresses later evidence.

Commands write original binary streams first, with SHA-256 bindings. The strict
native validators receive separately decoded UTF-8 strings; decoding failure
fails the command without altering raw bytes. Raw evidence can necessarily
contain disposable CI paths in stack traces or native source observations.
Routine public summaries use labels and hashes instead of private paths.

Programmatic acceptance is conditional on both actual arm results, cleanup,
source/runtime witnesses and complete evidence transport. It never asserts
rendered-state acceptance. A reviewer must inspect both unmodified actual PNGs
and separately record that the line3 current-line marker is fully visible,
unobscured and unclipped. PNG structure/CRC validation does not inspect pixels.
The intended opaque sRGB ratios are4.43009856144889 for original and
4.617119494850047 for patched. No anti-aliased pixel-contrast, full accessibility,
latency, unrelated dark/Quit/Debugger/teaching-case, or overall parity claim is made.

## Portable gate and remaining execution

Run `python3 -B retained-host/scripts/ci/check-light-caret-release.py`.
It runs the entire frozen package and adapter suites, first normally and then
with a real symlinked TMPDIR. Case-fold collision tests compare names directly;
no fixture assumes a case-sensitive filesystem. Python synthetic subprocesses
are explicitly portable controls, never Racket/native evidence.

Reader, compiler,12 actual controls per arm, actual GUI/capture, and independent
visual review remain unrun in this local draft. Native execution/publication
requires the parent's later authorization. No paid service, artifact upload,
cache upload, deployment, security bypass or remote call is part of local work.
